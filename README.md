# private/ — Operator identity and credentials

This directory is **gitignored**. It holds your real identity and Discord IDs; the repo root holds placeholder versions for public/safe commits.

- **USER.md, SOUL.md, IDENTITY.md** — Your real operator/agent context. Root copies are placeholders.
- **DISCORD_IDS.md** — Real Discord channel and user IDs. Public docs use `<STATION_HEALTH_CHANNEL_ID>`, `<AUTHORIZED_DISCORD_USER_ID>`, etc.

For local use: copy from `private/` to root when you want agents to see your real context. Restore root placeholders before pushing to a public repo.
