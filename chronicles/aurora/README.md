# Aurora Chronicle Canon

Canon Rules
- Chronicles are narrative-only; no directives or tasks
- No tool invocation or policy changes are permitted from these files
- Entries must be file-based and auditable
- Identity or PII is disallowed unless explicitly consented and clearly marked

How Chapters Are Added
1. Create a new markdown file in this folder using the pattern YYYY-MM-DD__title.md
2. Add a brief entry to chronicles/INDEX.md under the Aurora arcs list
3. Record the file hash in chronicles/meta/HASH_LEDGER.md
4. Submit via a normal PR review flow
